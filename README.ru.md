# Canon CMS

**AI-native headless CMS, в которой граф фактов — единый источник правды.**
*Измени факт один раз — сайт перепишет себя сам.*

[English](README.md) · **Русский**

---

## Что такое Canon

Canon — мультитенантная headless CMS для маркетинговых и продуктовых команд. В ней есть визуальный
конструктор страниц, структурированные коллекции, мультидоменный рендерер и REST API, а AI встроен
во все части.

Главное отличие — **Canon, граф фактов**. Цены, лимиты, даты и другие утверждения хранятся один раз,
как типизированные факты с историей версий. Canon находит каждое упоминание факта на всех сайтах и
языках, включая перефразировки. Когда факт меняется, команда AI-агентов переписывает затронутые
тексты в ветке на ревью, а человек её сливает.

```
Факт «Цена тарифа Pro» $49 → $59
   └─► линтер находит 14 упоминаний на 6 страницах в 3 локалях (включая «сорок девять долларов»)
        └─► Strategist → Copywriter / Translator → Fact-checker переписывают их в ветке
             └─► редактор смотрит дифф по каждому фрагменту → слияние (CAS) → публикация → сайт обновлён
```

## Возможности

**Контент**
- Визуальный конструктор: drag and drop, вложенные макеты, брейкпоинты, undo/redo, AI для отдельного блока и целой страницы.
- Коллекции со схемой полей, связями, валидацией черновика и публикации, импортом/экспортом CSV и JSON, headless API контента.
- Мультидоменный рендерер (Next.js): ISR, ревалидация по событию, превью, локали и hreflang.
- Медиатека с вариантами изображений и AI-подписями (alt).

**AI**
- Шлюз, не привязанный к провайдеру (Anthropic, OpenAI, Google, Ollama), с фолбэками и кэшем. Он же применяет защитные фильтры, маскирует персональные данные, следит за квотами и бюджетом каждого тенанта и ведёт учёт расходов.
- RAG: гибридный поиск (полнотекстовый + pgvector, RRF) и ответы по контенту со ссылками на источники.
- AI Studio: версии промптов, ReAct-агенты с инструментами только для чтения, площадка для сравнения моделей.
- Автотеги, саммари, оценка качества и поиск дублей для записей.

**Граф фактов Canon**
- Типизированные факты с историей и анализом влияния; линтер противоречий (детерминированный + LLM).
- Привязка текста к факту токеном — такой фрагмент не может разойтись с фактом.
- Команда агентов распространяет изменения в ветках на ревью; слияние проходит с проверкой версии (CAS).

**Рост**
- Совместное редактирование в реальном времени (Yjs): присутствие, undo только своих правок, автосохранение одним выбранным «лидером».
- Собственная аналитика без сторонних сервисов, с уважением к приватности и AI-инсайтами.
- A/B-тесты: вариант назначается при запросе к сайту, статистика корректна даже при просмотре до конца теста.
- Персонализация по сегментам аудитории.

**Платформа и enterprise**
- Биллинг через Stripe: оформление подписки, клиентский портал, повторные списания, оплата AI сверх лимита по факту.
- Плагины и маркетплейс: интеграции действуют через API-ключ с ограниченными правами после явного согласия и могут добавлять готовые секции в конструктор.
- Вебхуки: подпись HMAC, повторы, журнал доставок, защита от SSRF.
- **MCP-сервер** для AI-агентов: доступные инструменты зависят от прав ключа, публиковать агенты не могут.
- SAML single sign-on: домены подтверждаются через DNS, пользователи создаются при первом входе.
- Журнал аудита с ежедневной цепочкой хешей, экспорт и удаление данных по GDPR, экспорт воркспейса.
- Изоляция тенантов на уровне Postgres (row-level security), RBAC, 2FA, API-ключи.

## Технологии

| Слой | Технологии |
|---|---|
| API | NestJS 11 (модульный монолит), Prisma 6, Zod, BullMQ, transactional outbox |
| Данные | PostgreSQL 16 + pgvector (RLS, партиции, HNSW, tsvector), Redis 7, S3 |
| Админка | Next.js 16, React 19, TanStack Query, Zustand + zundo, dnd-kit, TipTap 3, Tailwind |
| Рендерер | Next.js 16, мультидоменный proxy, ISR |
| Realtime | Yjs, y-protocols поверх WebSocket, рассылка через Redis |
| AI | адаптеры Anthropic / OpenAI / Google / Ollama, Langfuse, OpenTelemetry |
| Интеграции | Stripe, SAML 2.0 (`@node-saml/node-saml`), Model Context Protocol SDK |
| Инструменты | pnpm workspaces, Turborepo, Vitest, Testcontainers, Docker |

## Архитектура

```
браузер ── админка (Next.js) ──/api/v1──► API (NestJS) ──► Postgres + pgvector (RLS)
   │            └── ws: /api/v1/collab ──┘       │   ├──► Redis (очереди, кэш, realtime)
посетитель ── рендерер (Next.js, ISR) ── delivery┘   ├──► S3 (медиа)
AI-агенты ── MCP /v1/mcp ──► API                     └──► LLM-провайдеры · Stripe · IdP · вебхуки
```

API не хранит состояния и заодно выполняет фоновые задачи: outbox, вебхуки, AI-обогащение, агентов
Canon, агрегаты аналитики, биллинг, запечатывание аудита. Их координирует BullMQ, поэтому реплики
можно добавлять свободно. Подробности (C4, модель данных, AI-поток, события, решения) — в
[docs/architecture.md](docs/architecture.md).

## Быстрый старт

Нужны Node ≥ 20.11, Docker Desktop и Corepack (один раз выполнить `corepack enable`).

```bash
corepack enable
```

```bash
pnpm install
```

```bash
cp .env.example .env
```

В `.env` задайте `SEED_ADMIN_PASSWORD` (не короче 12 символов) и `ENCRYPTION_KEY`. Ключ можно
сгенерировать командой `node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"`.
Для настоящих ответов AI добавьте хотя бы один из ключей `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`,
`GOOGLE_API_KEY` или запустите Ollama. Без них Canon тоже работает — на детерминированных фолбэках.

```bash
pnpm infra:up
```

```bash
pnpm db:migrate
```

```bash
pnpm db:seed
```

```bash
pnpm dev
```

- Админка: <http://localhost:3000>. Зарегистрируйтесь (письмо с подтверждением придёт в Mailpit — <http://localhost:8035>) или войдите под `SEED_ADMIN_EMAIL` / `SEED_ADMIN_PASSWORD`.
- Сайты: <http://localhost:3001>; адрес каждого сайта — `<site>-<tenant>.canon.localhost:3001`.
- Документация API (OpenAPI): <http://localhost:4000/api/docs> · здоровье: <http://localhost:4000/health/ready> · метрики: <http://localhost:4000/metrics>

## Скрипты

| Команда | Что делает |
|---|---|
| `pnpm infra:up` / `infra:up:full` / `infra:down` | сервисы в Docker (основные / + Langfuse и Ollama / остановить) |
| `pnpm db:migrate` / `db:migrate:dev` / `db:seed` / `db:reset` | применить миграции / создать новую / демо-данные / сброс |
| `pnpm dev` | API, админка и рендерер в режиме разработки |
| `pnpm build` / `typecheck` / `test` | пайплайны Turborepo (unit-тесты) |
| `pnpm test:integration` | интеграционные тесты API на временных контейнерах Postgres и Redis (нужен Docker) |
| `pnpm --filter @canon/api test:coverage` | unit- и интеграционные тесты с отчётом покрытия V8 |

## Деплой

Один Dockerfile собирает четыре образа (`api`, `admin`, `web`, `migrate`). Для запуска в production есть:

- `deploy/docker-compose.prod.yml` — для одного сервера;
- `deploy/k8s/canon.yaml` — для Kubernetes (пробы, PDB, HPA, ingress с поддержкой WebSocket).

В [docs/deployment.md](docs/deployment.md) описаны роли БД, справочник переменных окружения,
настройка Stripe и SAML, масштабирование, бэкапы, обновления и чек-лист безопасности (документ на
английском).

## Известные ограничения

- Из этого окружения не вызывались настоящие LLM-провайдеры, Stripe и SAML-провайдеры. Адаптеры
  проверены типами по официальным SDK и API, а сценарии покрыты интеграционными тестами с
  фейками: фейковый Ollama, фейковый сервер Stripe и SAML-ответы, подписанные тестовыми
  сертификатами.
- Цены моделей в сиде нужно сверить со страницами тарифов провайдеров до запуска биллинга.
